# Classroom Manager v2.80

班級管理、作業追蹤、聯絡簿、出缺席、成績、座位與課堂工具。

## 使用方式
將 `index.html`、`style.css`、`app.js` 部署至 GitHub Pages。資料儲存在瀏覽器 localStorage，請定期匯出 JSON 備份。

## v2.80 更新
- 以 v2.79 原始 ZIP 為基礎，擴大作業及聯絡簿日期欄位與操作按鈕間距，改善 iPad Safari 觸控操作。
- 公告與備忘事項表單日期、內容欄位加寬留白，按鈕與上方欄位增加垂直距離。
- 窄螢幕改為單欄排列，修正程式內 APP_VERSION 與頁面快取版本不一致。
- 不變更資料結構與操作邏輯。
