# Classroom Manager v2.79

班級管理、作業追蹤、聯絡簿、出缺席、成績、座位與課堂工具。

## 使用方式
將 `index.html`、`style.css`、`app.js` 部署至 GitHub Pages。資料儲存在瀏覽器 localStorage，請定期匯出 JSON 備份。

## v2.79 更新
- 作業、聯絡簿日期篩選：日期與操作按鈕分成獨立欄位，保留 28px 間距。
- 總覽設定公告與備忘：日期、內容、送出按鈕分欄分列，避免 Safari 原生日期欄位擠壓。
- 手機寬度改為單欄排列；不修改資料與功能邏輯。
