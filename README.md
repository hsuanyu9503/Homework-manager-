# Classroom Manager v2.99

部署：將 index.html、style.css、app.js 上傳至 GitHub Pages。資料保存在瀏覽器 localStorage，請定期匯出備份。

## 新增：今日作業提醒
- 學生頁新增全班卡片式提醒與展示模式，原有學生個別作業追蹤保留。
- 預設每人 3 項、隱藏無待處理學生、顯示缺交／待訂正狀態。
- 按作業日期由舊到新排序；同一天缺交優先；只讀顯示，不修改作業狀態。
- 教師可設定每人顯示 1–6 項、是否隱藏無待處理學生、是否顯示狀態；設定隨班級儲存。
- 卡片可顯示超出限制的待處理數量；展示模式隱藏其他學生管理區塊。

## v2.82 更新
- 作業狀態變更時即時更新全班提醒卡片，不打斷原本作業視窗操作。
- iPad 橫向展示固定三欄；窄螢幕改兩欄／單欄，長作業名稱自動換行。
- 卡片等高與間距調整，原有學生個別追蹤維持不變。

## v2.83 更新
- 學生頁新增「學生作業追蹤／今日作業提醒」切換頁籤；預設顯示原本學生追蹤。
- 提醒設定、卡片和展示模式僅在提醒頁顯示；追蹤頁保留學生搜尋、出缺席和學生卡片。
- 離開展示模式切換至追蹤頁時自動結束展示；原本作業紀錄與排序邏輯不變。


## v2.84
- 學生頁標題與說明依「學生作業追蹤／今日作業提醒」切換。
- 手動切換子頁時自動捲至學生區塊頂端；背景更新不會強制捲動。
- 原本展示模式、作業排序與追蹤資料保留不變。


## v2.85 — 日期欄位與 iPad 展示優化
- 作業、聯絡簿頁面「選擇日期」改為與網站主要文字相同的深灰色，日期在框內水平置中。保留原生日期選擇器。
- 學生雙模式切換回到可見標題位置，避開 sticky 導覽列；使用 Safari 支援的捲動設定。
- 進出今日提醒的展示模式時直接切換樣式，避免反覆重建卡片；展示字級與留白微調。
- 保持既有 localStorage 資料格式與儲存鍵不變，以避免升版導致班級資料遺失。


## v2.86 — 日期文字垂直置中
- 修正作業與聯絡簿頁面「選擇日期」在 iPad Safari 日期欄位中的垂直對齊：取消上下內距，讓 WebKit 日期文字容器與 48px 輸入框等高並置中。
- 保留 v2.85 的水平置中、深灰色文字、252px 欄位寬與原生日期選擇功能；其他資料處理功能不變。


## v2.87 — 投影展示／學生追蹤登記
- 今日作業提醒「展示模式」改為獨立的全畫面唯讀介面，僅有返回按鍵與學生提醒卡片；隱藏所有教師設定、網站導覽和頁尾。按 Escape 或返回按鍵即可退出。
- 學生頁的「學生作業追蹤」：點選學生後，可直接將各項作業改成「未確認／已交／待訂正／完成／缺交」，並修改備註，不必跳至全班作業視窗；同時保留每項作業「查看全班作業」入口。
- 預設隱藏已完成紀錄，但可點選「顯示已完成」重新更正已完成的作業；更新後自動同步學生摘要和今日提醒。
- 維持原有 localStorage 鍵值、班級資料格式、作業排序和座位展示功能。


## v2.88 — 相容性與文件修正
- 修正缺少 `createdAt` 建立時間的舊作業紀錄在相同日期排序時可能造成的錯誤；改用安全字串比較，不變更正常資料的排序順序。
- 修正 README 中 v2.85、v2.86 更新紀錄誤標為 v2.87 的問題。
- 保留 v2.87 的今日作業提醒全畫面展示與學生個別狀態、備註直接編輯功能。


## v2.89 — 學生作業追蹤排序
- 點選學生，個別作業追蹤視窗新增「日期排序／名稱排序」切換按鍵。
- 日期排序預設新到舊，同日依作業名稱排列；名稱排序依中文名稱（含數字自然順序），同名則按日期新到舊。
- 排序選擇在切換不同學生時保留，切換排序時維持視窗原捲動位置。
- 「顯示已完成」、狀態直接登記、備註修改與返回全班作業功能維持不變。
- 排序僅影響個別學生視窗的清單呈現，不改動作業資料及「今日作業提醒」既有優先順序。


## v2.90 — 學生作業追蹤排序方向
- 個別學生的作業紀錄視窗新增「↑ 遞增／↓ 遞減」切換鍵，搭配既有「日期排序／名稱排序」，共四種排列方式。
- 日期：遞增＝舊到新；遞減＝新到舊（預設）。名稱：遞增＝中文名稱由前到後（預設）；遞減＝名稱由後到前。數字採自然排序，例如「第 2 回」在「第 10 回」前。
- 日期與名稱分別記住本次使用時的排序方向；切換學生及狀態編輯時保留目前選項。切換排序維持視窗捲動位置。
- 僅改變個別學生視窗的顯示順序；不改寫作業資料、不影響今日作業提醒的優先排序，也不更動班級 localStorage 格式。

## v2.91 — 學生作業排序精簡控制
- 個別學生視窗將排序控制精簡為三個按鍵：「日期」、「名稱」、「↑／↓」。
- 箭頭在**同一個按鍵**切換遞增（↑）或遞減（↓）；日期與名稱分別保留各自的排序方向。
- 排序按鍵增加語意標籤與說明提示，方便螢幕閱讀器與滑鼠查看。
- 手機、iPad 排版縮減佔用空間；「顯示已完成」、作業狀態及備註編輯保持不變。
- 僅變更學生作業追蹤視窗的控制外觀，不變更排序演算法及今日作業提醒的排序。


## v2.92 — 學生個別作業優先排列
- 個別學生「學生作業追蹤」視窗自動依狀態排序：缺交優先、待訂正次之，其餘狀態顯示於後方。
- 每個狀態群組內仍沿用目前日期／名稱及 ↑↓ 排序設定；無論遞增或遞減，都不會把缺交與待訂正排到後面。
- 狀態修改後即時重新排序；隱藏／顯示已完成作業、教師備註、今日作業提醒及班級資料格式維持原有行為。


## v2.93 — 舊資料相容性與避免資料回溯
- 不改變主要 `homeworkTrackerDataV2` 儲存鍵與班級資料格式；舊版資料正常繼續使用。
- 新增「舊分頁覆寫保護」：儲存前檢查資料是否已由其他分頁修改。若有衝突，暫停寫入、顯示持續警示，提供「下載本頁資料備份」和「重新載入最新資料」。
- 資料讀取失敗／內容格式不正確時禁止用空班級資料覆寫原儲存內容；儲存空間寫入失敗亦會顯示警示。
- 班級首頁編輯學生名單時保留原有學生註記與其他欄位（以座號比對）。
- 匯入 JSON 前驗證基本班級資料陣列；拒絕誤選的非班級 JSON，避免匯入後變成空資料。
- 資料保護僅涵蓋已升級至本版的分頁；**更新前務必關閉舊版分頁並匯出 JSON 備份**。不同裝置的 localStorage 並不會自動同步。


## v2.94 — 點選座位翻牌揭曉（純座位卡）
- 「座位揭曉展示」直接在座位配置上操作：尚未揭曉只顯示「？」；點選某個已安排學生的位置，以 3D 翻牌顯示其座號及姓名。
- 已揭曉的座位保持翻開，不需學生姓名字卡；封鎖座位與空位不參與揭曉。
- 展示內提供「← 返回」、「全部揭曉」、「重新隱藏」，支援鍵盤 Enter／空白鍵揭曉及 Esc 返回，並尊重減少動畫的系統偏好。
- 每次進入展示重新隱藏所有座位，揭曉記錄只存在當次畫面、不寫入任何班級資料，也不變更座位分配、歷史紀錄及 v2.93 儲存衝突保護。
- 保留教師／學生視角的座位位置與黑板方向；座位管理模式仍可拖曳交換與封鎖。
- 補強既有座位資料載入：`seating.blocked` 封鎖座位標記隨舊班級資料一併保留，避免在讀取／升版過程中遺失；不重新安排座位。


## v2.98 — 座位投影空間與講臺比例調整
- 以 iPad 橫向 1408 × 1056 尺寸為主，降低展示模式座位卡的高度並設上限，避免格子為填滿畫面而被過度拉長。
- 擴大「黑板／講臺」的寬度、厚度與字體，調整主內容和講臺的間距，改善視覺比例。
- 學生字卡區跟隨新的座位區高度平均排列；窄螢幕維持上下排列，允許縱向捲動。
- 僅修改展示樣式與版本資訊：雙向揭曉、封鎖座位、座位分配與 v2.93 資料安全防護程式不變。

## v2.97 — 投影版面細部比例校正與校對

## v2.96 — 座位投影比例優化

## v2.95 — 學生圖卡 × 座位雙向揭曉

- 點選學生字卡會翻開其座位；點選座位也會同步翻開對應學生字卡。已揭曉保持顯示，避免重複揭曉。

- 窄螢幕時學生字卡自動移至座位表上方，避免遮擋座位。


## v2.99 — 可選用期中／期末成績區段
- 成績頁「期中／期末設定」由教師決定是否啟用，預設停用，升級舊資料不會自動變更成績總覽。
- 啟用後，「成績總覽」新增「全部／期中／期末」切換，科目篩選仍可同時使用。
- 每個成績項目只能選擇「不計入」「期中」或「期末」其中一個歸屬，保證單一評量不會被兩邊重複計算。
- 可集中設定舊評量項目的區段，也能於新增／編輯成績項目時直接指定。
- 學生百分制平均沿用既有計算方式，但只計入目前所選區段的已登記項目；未分配項目只出現在「全部」總覽。
- 停用區段只會還原原本的全項目總覽，不刪除已設定的歸屬或學生分數，重新啟用可保留設定。
- 舊版匯入資料缺少區段欄位時，預設為「未分配」且功能停用；維持 v2.93 以來的跨分頁防覆寫保護。
- 原有作業、座位雙向揭曉、出缺席、課堂工具與資料格式保持相容。
