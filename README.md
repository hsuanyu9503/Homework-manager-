# 學生作業追蹤 Homework Tracker

這是一個純前端、可直接部署到 GitHub Pages 的個人版學生作業追蹤工具。

## 目前功能

- 班級名稱與學生名單設定
- 依日期新增作業
- 五種狀態：未確認、已交、待訂正、完成、缺交
- 總覽頁置頂顯示缺交與待訂正
- 依日期查看作業
- 查看單一學生歷史紀錄
- JSON 完整備份
- JSON 匯入還原
- 清除本機資料
- 手機 / 平板 / 電腦響應式介面

## 資料儲存方式

資料儲存在瀏覽器的 `localStorage`。

因此：

- 同一台裝置、同一個瀏覽器再次開啟網站時，資料仍會保留。
- 換裝置、換瀏覽器或清除網站資料後，原資料不會自動同步。
- 建議定期使用「設定 → 匯出備份」下載 JSON 備份檔。
- 在其他裝置開啟網站後，可使用「匯入備份」還原資料。

## GitHub Pages 部署

1. 在 GitHub 建立一個新的 repository，例如 `homework-tracker`
2. 將以下檔案上傳到 repository 根目錄：
   - `index.html`
   - `style.css`
   - `app.js`
3. 進入 repository 的 `Settings`
4. 開啟 `Pages`
5. 在 `Build and deployment` 中選擇 `Deploy from a branch`
6. Branch 選 `main`，資料夾選 `/ (root)`
7. 儲存後等待 GitHub Pages 建立網址

## 學生名單格式

可以輸入：

```text
1 王小明
2 陳小華
3 林小安
```

也可以只輸入：

```text
王小明
陳小華
林小安
```

系統會自動從 1 開始編號。

## 操作說明

在單一作業的學生列表中，點擊狀態按鈕會依序循環：

`未確認 → 已交 → 待訂正 → 完成 → 缺交 → 未確認`

每位學生也可以輸入備註，例如「第 3 題」、「明天補交」。

## 隱私提醒

若使用真實學生姓名，請注意：

- GitHub repository 可以公開，但學生資料本身只存放在你的瀏覽器，不會被寫進 repository。
- 不要將包含真實學生資料的 JSON 備份檔上傳至公開 GitHub repository。
- 若日後改成雲端同步版，需另外處理帳號驗證與資料權限。
