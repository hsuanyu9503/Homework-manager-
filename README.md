# Classroom Manager v2.73

適用於 GitHub Pages 的班級管理工具，使用 HTML、CSS 與 JavaScript，無須後端伺服器。

## 主要功能

- 多班級與學生管理、班級資料設定
- 作業繳交／訂正／缺交追蹤與統計
- 聯絡簿、公告與備忘錄
- 出缺席登記、假別與備註、日期查詢、點名完成及異動提醒
- 成績管理、座位安排、課堂工具
- 各分頁密碼保護、班級資料 JSON 備份／匯入

## 點名確認密碼

預設為 `1234`。進入「班級資料管理」可修改各班的點名確認密碼（4～12 碼）。完成點名及重新確認時需輸入密碼。密碼欄右側的眼睛圖示**按住顯示、放開隱藏**，包含分頁密碼欄位。

這是前端操作確認機制，**不是**伺服器身分驗證或資料加密；請勿用於存放高度敏感資訊。

## 使用與部署

將 `index.html`、`style.css`、`app.js` 上傳至 GitHub Pages 網站根目錄即可使用。更新版本時請一起替換三個檔案，必要時重新整理瀏覽器以清除快取。

資料儲存在使用裝置及瀏覽器的 `localStorage`，不同裝置不會自動同步。請定期匯出 JSON 備份。

## 本版更新（v2.73）

- 在「班級資料管理」新增各班獨立的作業缺交判定時間（24 小時制 HH:mm），預設 `12:00`。
- 批改日仍是作業日期的下一個實際上課日；當天到達指定時間才將未確認作業轉缺交。
- 網頁開啟時每分鐘檢查，切回分頁時補檢；變更設定後立即重新檢視。
- 設定會隨班級 JSON 備份／匯入保存；原有請假與教師手動狀態規則不變。

- v2.73：調整班級管理中的作業缺交判定時間欄位，縮小輸入框並保留右側間距，改善 iPad 排版。
