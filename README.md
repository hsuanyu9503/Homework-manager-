# Classroom Manager v2.83

部署：將 index.html、style.css、app.js 上傳至 GitHub Pages。資料保存在瀏覽器 localStorage，請定期匯出備份。

## 新增：今日作業提醒
- 學生頁新增全班卡片式提醒與展示模式，原有學生個別作業追蹤保留。
- 預設每人 3 項、隱藏無待處理學生、顯示缺交／待訂正狀態。
- 按作業日期由舊到新排序；同一天缺交優先；只讀顯示，不修改作業狀態。
- 教師可設定每人顯示 1–6 項、是否隱藏無待處理學生、是否顯示狀態；設定隨班級儲存。
- 卡片可顯示超出限制的待處理數量；展示模式隱藏其他學生管理區塊。
