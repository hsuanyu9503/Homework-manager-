# Classroom Manager v2.88

部署：將 index.html、style.css、app.js 上傳至 GitHub Pages。資料保存在瀏覽器 localStorage，請定期匯出備份。

## 新增：今日作業提醒
- 學生頁新增全班卡片式提醒與展示模式，原有學生個別作業追蹤保留。
- 預設每人 3 項、隱藏無待處理學生、顯示缺交／待訂正狀態。
- 按作業日期由舊到新排序；同一天缺交優先；只讀顯示，不修改作業狀態。
- 教師可設定每人顯示 1–6 項、是否隱藏無待處理學生、是否顯示狀態；設定隨班級儲存。
- 卡片可顯示超出限制的待處理數量；展示模式隱藏其他學生管理區塊。

## v2.82 更新
- 作業狀態變更時即時更新全班提醒卡片，不打斷原本作業視窗操作。
- iPad 橫向展示固定三欄；窄螢幕改兩欄／單欄，長作業名稱自動換行。
- 卡片等高與間距調整，原有學生個別追蹤維持不變。

## v2.83 更新
- 學生頁新增「學生作業追蹤／今日作業提醒」切換頁籤；預設顯示原本學生追蹤。
- 提醒設定、卡片和展示模式僅在提醒頁顯示；追蹤頁保留學生搜尋、出缺席和學生卡片。
- 離開展示模式切換至追蹤頁時自動結束展示；原本作業紀錄與排序邏輯不變。


## v2.84
- 學生頁標題與說明依「學生作業追蹤／今日作業提醒」切換。
- 手動切換子頁時自動捲至學生區塊頂端；背景更新不會強制捲動。
- 原本展示模式、作業排序與追蹤資料保留不變。


## v2.85 — 日期欄位與 iPad 展示優化
- 作業、聯絡簿頁面「選擇日期」改為與網站主要文字相同的深灰色，日期在框內水平置中。保留原生日期選擇器。
- 學生雙模式切換回到可見標題位置，避開 sticky 導覽列；使用 Safari 支援的捲動設定。
- 進出今日提醒的展示模式時直接切換樣式，避免反覆重建卡片；展示字級與留白微調。
- 保持既有 localStorage 資料格式與儲存鍵不變，以避免升版導致班級資料遺失。


## v2.86 — 日期文字垂直置中
- 修正作業與聯絡簿頁面「選擇日期」在 iPad Safari 日期欄位中的垂直對齊：取消上下內距，讓 WebKit 日期文字容器與 48px 輸入框等高並置中。
- 保留 v2.85 的水平置中、深灰色文字、252px 欄位寬與原生日期選擇功能；其他資料處理功能不變。


## v2.87 — 投影展示／學生追蹤登記
- 今日作業提醒「展示模式」改為獨立的全畫面唯讀介面，僅有返回按鍵與學生提醒卡片；隱藏所有教師設定、網站導覽和頁尾。按 Escape 或返回按鍵即可退出。
- 學生頁的「學生作業追蹤」：點選學生後，可直接將各項作業改成「未確認／已交／待訂正／完成／缺交」，並修改備註，不必跳至全班作業視窗；同時保留每項作業「查看全班作業」入口。
- 預設隱藏已完成紀錄，但可點選「顯示已完成」重新更正已完成的作業；更新後自動同步學生摘要和今日提醒。
- 維持原有 localStorage 鍵值、班級資料格式、作業排序和座位展示功能。


## v2.88 — 相容性與文件修正
- 修正缺少 `createdAt` 建立時間的舊作業紀錄在相同日期排序時可能造成的錯誤；改用安全字串比較，不變更正常資料的排序順序。
- 修正 README 中 v2.85、v2.86 更新紀錄誤標為 v2.87 的問題。
- 保留 v2.87 的今日作業提醒全畫面展示與學生個別狀態、備註直接編輯功能。
